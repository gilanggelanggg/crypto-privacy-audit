Deep Technical Analysis: Chainalysis Heuristics & Crystal AML Scoring Mechanisms

1. Common Input Ownership (CIO) Heuristic

Chainalysis Reactor applies the Common Input Ownership heuristic under the assumption that multiple inputs in a single Bitcoin transaction originate from the same entity or wallet cluster. This assumption allows analysts to group addresses into clusters, which can then be assigned risk scores based on historical associations with illicit activity. 

Cluster Risk Score = Σ(P(taint_i)) / N_inputs
Where:
- P(taint_i): Probability that input i is associated with flagged activity
- N_inputs: Total number of inputs in the transaction

2. Change Address Identification (CAI)

To refine clustering accuracy, Crystal AML employs Change Address Identification, leveraging deterministic patterns in address reuse and output value distributions. For instance, if one output matches an exact denomination from prior transactions (e.g., a round number), it is likely the change address belonging to the sender. 

P(change) = f(address_age, output_value_match, script_type)
Where:
- address_age: Time since last use of the address
- output_value_match: Whether the output amount aligns with known denominations
- script_type: Script format consistency (P2PKH, P2SH, Bech32)

3. Transitive Linkage and Taint Propagation

Once clusters are established, taint propagates through successive transactions. Each new hop introduces additional confidence levels, increasing the cumulative probability that downstream UTXOs carry residual taint. 

Taint Propagation Formula:
T_out = T_in × (1 - ε)^hops + γ
Where:
- T_in: Initial taint score of source UTXO
- ε: Decay factor per hop (typically 0.1–0.3)
- γ: Noise injection constant (to account for randomization)

4. Exchange Risk Scoring Integration

Exchanges integrate these scores directly into their Know Your Customer (KYC) systems. When a deposit exhibits a taint score above a predefined threshold (often set at 5%), automated withdrawal holds or account freezes may occur.

Technical FAQ

Q1: What causes a Bitcoin taint score check to flag a transaction?

A taint score increases when any component of a transaction—input or output—is linked to known illicit activity through historical tagging, ransomware payments, darknet markets, or sanctions lists. Tools like Chainalysis Reactor calculate this via probabilistic clustering algorithms.

Q2: Is using a bitcoin mixer legal?

Bitcoin mixers themselves are not inherently illegal. However, their misuse for obfuscating proceeds from criminal activity constitutes AML taint mitigation under applicable laws. Users must ensure full compliance with local regulations. In many jurisdictions, privacy-focused usage remains protected under constitutional rights to financial privacy.

Q3: How do I avoid an exchange account freeze after receiving tainted coins?

To minimize risk:

  • Use trusted privacy-enhancing services (PES) before depositing.
  • Run taint analysis locally prior to deposit submission.
  • Maintain transparent audit trails for legitimate sources.
  • Never deposit directly from flagged wallets or exchanges.

Q4: Can blockchain heuristics be bypassed effectively?

Yes, through methods such as:

  • CoinJoin batching (as implemented by Wasabi Wallet, JoinMarket)
  • UTXO splitting and consolidation across unrelated nodes
  • Use of privacy-centric chains (Monero, Zcash)
  • Decentralized mixing protocols without centralized points of failure
These techniques disrupt heuristic correlation models by introducing entropy and breaking deterministic assumptions.

Q5: What does “how to clean dirty crypto” mean technically?

“Cleaning” refers to the process of severing links between a given UTXO and its tainted history. This involves:

  • Passing funds through multi-hop mixers
  • Splitting large amounts into smaller units
  • Introducing time delays between steps
  • Using off-chain intermediaries where possible
A successful operation yields UTXOs with a taint score approaching zero.
